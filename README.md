# 🔳 QR Code Generator

A simple and user-friendly QR Code Generator built using Python. This application allows users to generate QR codes from text or URLs and save them as image files using a graphical interface.

---

## 📌 Features

* Generate QR codes from text or URLs
* Easy-to-use GUI built with Tkinter
* Save QR codes as PNG images
* Customizable QR code size (1–40)
* Lightweight and beginner-friendly

---

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* qrcode library
* PIL (Pillow)

---

## ▶️ How to Run

1. Install required library:

   ```
   pip install qrcode[pil]
   ```

2. Run the Python file:

   ```
   python qr_generator.py
   ```

---

## 🧑‍💻 How to Use

1. Enter the text or URL
2. Enter the file save location
3. Enter file name
4. Choose QR size (1–40)
5. Click **Generate Code**
6. Your QR code will be saved successfully 🎉

---

## 📂 Output

* The generated QR code will be saved as a `.png` file in your selected location.

---

## ⚠️ Notes

* Make sure the file path is correct
* Size should be between 1 and 40
* All fields must be filled before generating QR
